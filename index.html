¿Quién está detrás de DAEX?

Soy estudiante de Ingeniería de Sistemas y me apasiona la tecnología, el desarrollo web y la creación de soluciones digitales. En DAEX creo páginas web personalizadas, buscando que cada proyecto tenga el diseño, estilo y funcionalidades que realmente necesita cada cliente.

No trabajo con una plantilla genérica: cada sitio se piensa y se construye desde cero, según el rubro, el estilo y los objetivos del negocio.

Cada negocio es diferente. Por eso, cada página también debe ser diferente.
